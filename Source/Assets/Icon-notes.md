# 关源图标

本文件记录旧版图标。v1.3.4 的当前图标与完整提示词见 Icon-v1.3.4.md；透明前景提示词见 Icon-foreground-prompt.md。

使用内置 image_gen 编辑原头像。最终提示：保持红白巫女人物、原图深红背景，头肩像居中缩小，四周保留约 15% 红色空白，蝴蝶结完整，无文字、边框或预制圆角。

portrait.png 为生成原图；AppIcon.png、ICO 和 Android PNG 只进行尺寸与格式转换。Android 自适应图标增加 16.67% 图层内缩，抵消系统对 108dp 图层的裁切放大。

## 内置 image_gen 完整提示词

Use case: identity-preserve. Edit target: image 2, the existing shrine maiden app icon portrait. Image 1 is the original character and red background color reference. Create one square app icon asset for GuanYuan. Preserve the girl's identity, face, dark brown hair, red-brown eyes, red-white bow, anime painting style. Reframe to a smaller centered head-and-shoulders avatar on the SAME muted crimson RED background as image 1. Leave visible red negative space on ALL FOUR sides, about 14-18% of the square canvas around the complete head-and-shoulders silhouette, especially above and beside the entire bow. The portrait should occupy only about 65-70% of the square width and height; center it visually in the square, with the face near the center. Shoulders end above the bottom margin with a natural soft fade into the red backdrop. Keep the entire large bow visible, no hair/bow cut off at canvas boundaries. Red background covers the full square edge to edge, subtle flat red tonal variation only, NOT cream or white, NOT transparent. No circle badge, no border, no text, no logo, no rounded corner mask baked into asset. This is intended to have breathing room when Android applies its launcher icon shape.
