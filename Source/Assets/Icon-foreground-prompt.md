# 安卓透明前景图层

使用内置 image_gen，transparent_background=true；输入为本版 portrait.png，输出为 portrait-foreground.png。保留生成的 alpha，仅缩放生成 Android PNG。安卓背景保持旧版 #A2262E，图层内缩 22.22%。

完整提示词：

Use case: background-extraction. This is an Android icon FOREGROUND layer, not a new illustration. Remove ONLY the outer deep crimson background from this shrine-maiden icon and replace it with genuine transparent alpha. Keep the entire girl exactly as pictured at the same size and position on the same square canvas: full red-white hair bow, dark brown hair including fine strands, red-brown eyes, face and expression, red-white shoulder clothing, yellow ribbon, and the curved bottom shoulder silhouette. Preserve all RED areas that belong to the bow, ribbons and clothes; only the background is transparent. Do not zoom, recenter, add padding, redraw, change colors, crop the bow, add shadows, add a badge, or add text. Clean antialiased edges without a red rectangular matte or fringe. The app supplies its own original red background underneath; output this one exact foreground with transparent background.
