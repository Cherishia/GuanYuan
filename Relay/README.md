# 关源跨网络中转

这是个人私有中转程序，不含已部署的公网服务。电脑主动连中转，家用路由器无需端口映射。手机可通过流量发出关机、睡眠、休眠、取消和状态查询。中转不保存配对密钥，指令和回执通过电脑与手机之间的 AES-256-GCM 加密，另保留原有签名、防重放和倒计时。

## 部署到你自己的服务器

需要：一台可长期运行 Docker Compose 的公网服务器，一个指向服务器的域名，80 / 443 端口可访问。

1. 上传本目录，复制 `.env.example` 为 `.env`。
2. 设置 `GUANYUAN_DOMAIN` 为域名，不含 `https://`。
3. 用密码管理器生成随机 32 字节十六进制密钥，填入 `GUANYUAN_RELAY_KEY`。例如已有 Node.js 时：`node -e "process.stdout.write(require('node:crypto').randomBytes(32).toString('hex'))"`。密钥只保存在自己的配置里，不要发到聊天或公开仓库。
4. 执行 `docker compose up -d --build`，Caddy 会为配置域名申请 HTTPS 证书。保留 Caddy 数据卷。
5. 电脑运行 `GuanYuan.exe`，打开「跨网络设置」，填写 `https://你的域名` 和同一密钥。
6. 手机和电脑连同一 Wi-Fi，在关源连接这台电脑一次，手机会自动接收并保存加密的远程配置。
7. 手机关闭 Wi-Fi，使用流量打开关源，选择保存的远程入口。先核对「已连接」及电脑状态，再进行电源操作。

只有配置成功后才能跨网控制。已有局域网配对保留；无需扫码。电脑退出、断网、关机、睡眠后无法接收指令，本版不支持远程开机。

## 服务行为

- 服务只服务同一个拥有者的设备；中转访问密钥是该拥有者的共享服务凭证，不用于多人公共托管。
- 所有接口需 Bearer 中转密钥。生产客户端只允许 HTTPS，验证系统证书，不跟随重定向。
- 最多 64 台电脑、每台 8 个等待请求，响应 12 秒超时，电脑端再次核验 15 秒指令有效期。不会把离线关机任务保存到以后执行。
- 电脑保持一个最长 20 秒的等待连接；连接失败指数退避至 30 秒。没有手机轮询时也会有少量心跳流量。
- 若手机提示「未收到电脑回执」，先查询状态；电脑可能已收到指令。手机不会自动重发电源操作。
- 关闭跨网：在电脑的「跨网络设置」里点击「关闭跨网络」，再让手机同 Wi-Fi 连接一次以移除远程入口。手机也可单独移除入口。
- 密钥泄露时在服务器 `.env` 换新值，重建容器，再更新电脑设置并重新同步手机。清除配对会立即撤销该手机的控制权限。

服务器没有网页账号、远程配对、文件访问、任意命令执行或离线指令存储。只提供固定电源协议的加密消息传递。请保留服务器基础的系统更新和资源限制。
